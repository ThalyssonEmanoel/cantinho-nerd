1. Gerenciamento de Tokens e Imagens
Persistência de Dados (Token): Permitir a alteração do nome do token e adicionar um botão Salvar para que a modificação seja permanente no banco de dados/armazenamento local.

Persistência de Dados (Imagens): Aplicar a mesma lógica de salvamento permanente para o upload ou troca de imagens.

Categorização para o Mestre: Expandir as categorias de tokens exclusivas do mestre. Atualmente o sistema só suporta "Monstros"; é necessário criar uma nova categoria para NPCs (Personagens Não Jogáveis).

2. Ferramentas do Canvas / Tabuleiro
Histórico de Ações (Ctrl + Z): Implementar a função de desfazer (Ctrl + Z) para os traços do lápis e para a inserção de figuras geométricas/formas.

Ferramenta Borracha: Adicionar uma ferramenta de borracha para apagar elementos específicos do traçado de forma parcial, evitando a necessidade de limpar toda a tela.

Limpeza de Dados: Adicionar um botão ou opção para Limpar Histórico de Dados (resetar o estado do tabuleiro/sessão).

3. Mapas e Medidas
Ajuste de Escala (Régua): Alterar a unidade de medida da ferramenta régua de grid/pixels para metros.

Dimensões do Mapa: Melhorar o gerenciamento do diâmetro/tamanho dos mapas, permitindo resoluções maiores ou um ajuste de área de trabalho mais otimizado. Atualmenete algumas imagens ficam com bordas pretas nas laterais, pois não complementão as laterais. Tentar achar alguma solução que não deixe as imagens muito esticadas.

Possibilitar zoom dinâmico para ter a possibilidade de visualizar melhor detalhes no mapa.
